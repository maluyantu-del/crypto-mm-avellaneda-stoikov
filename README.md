# Avellaneda–Stoikov 做市报价模型:接入 OKX 实时订单簿的入门实现

以 OKX 现货 BTC/USDT 的实时订单簿为输入,实现 Avellaneda–Stoikov(2008)最优做市报价公式,比较模型报价与市场实际价差,并考察库存对储备价的影响。定位为做市机制的学习型实现,不含成交模拟与回测。

## 文件

| 文件 | 内容 |
|---|---|
| `test_ccxt.py` | 通过 ccxt 获取 OKX BTC/USDT 最新成交价、24 小时高低价与成交量,验证接口连通 |
| `orderbook.py` | 获取前 10 档订单簿(失败重试 3 次),输出买卖盘、中间价与价差(USDT 与 bp) |
| `as_model.py` | 以实时中间价为输入计算 AS 储备价与最优价差,比较库存为 0、+1、−1 BTC 三种情形,并与市场价差对照 |

## 模型

储备价与最优总价差:

```
r      = s − q · γ · σ² · (T − t)
δ_a+δ_b = γ · σ² · (T − t) + (2/γ) · ln(1 + γ/κ)
bid = r − (δ_a+δ_b)/2,  ask = r + (δ_a+δ_b)/2
```

s 为中间价,q 为库存,γ 为风险厌恶系数,σ 为价格波动率,κ 为订单到达强度的衰减参数。库存为正时储备价下移,报价整体下调以促成卖出;库存为负时相反。

## 运行

```bash
python3 -m venv venv && venv/bin/pip install -r requirements.txt
venv/bin/python test_ccxt.py
venv/bin/python orderbook.py
venv/bin/python as_model.py
```

需能访问 OKX 公共行情接口,无需 API key。

## 已知问题:参数量纲不一致

公式中 σ 为**价格单位**的波动率(USDT),γ 与 κ 的量纲为 1/USDT。`as_model.py` 中 σ = 0.03 为**收益率口径**(日波动率 3%),与价格单位的中间价混用。以中间价 100,000 USDT、γ = 0.5、κ = 100、T = 1 离线复算:

| 量 | 数值 |
|---|---|
| 库存 +1 BTC 时储备价偏移 | −0.00045 USDT |
| 模型总价差 | 0.0204 USDT(0.0020 bp) |
| OKX BTC/USDT 典型价差(一个最小报价单位) | 约 0.1 USDT(0.01 bp) |

即在当前参数下,库存惩罚可以忽略,模型价差约为市场价差的五分之一。脚本末尾"关键洞察"中的文字结论("AS 价差过宽、挂单不会成交")为预先写定的文字,与上述计算结果不符,应以计算结果为准。该文字记录的三次调参(σ = 0.01 效果不可见、σ = 2000 储备价为负、σ = 0.03)均源于同一量纲问题:σ 换成价格单位后,γ 须相应缩小若干个数量级,κ 须按价格单位的报价距离重新标定。

修正方向:σ 取 中间价 × 收益率波动率(或直接用中间价序列的价格差标准差估计);γ 按"持有 1 单位库存时可接受的储备价偏移"反推;κ 由成交到达率随报价距离的衰减拟合。

## 局限

- 单次快照计算,无逐笔成交、无库存演化、无盈亏统计。
- σ、γ、κ 为手设参数,未用历史数据标定。
- 未考虑最小报价单位、手续费与返佣、逆向选择。

## 参考文献

- Avellaneda, M., & Stoikov, S. (2008). High-frequency trading in a limit order book. *Quantitative Finance*, 8(3), 217–224.
